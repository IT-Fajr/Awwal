# أوّل 🏆

منصة زر تفاعلية للمسابقات الحية مبنية بـ HTML و JavaScript و Firebase.

## المميزات
- غرف مباشرة بكود فوري
- دقة أجزاء الثانية في تحديد الفائز
- وضع الفرق| المشرف يوزع المشاركين
- مؤقت إجابة قابل للتخصيص
- أيقونات وألوان مخصصة لكل مشارك
- ثيم ليلي ونهاري
- يعمل على جميع الأجهزة

## التقنيات
- HTML / CSS / JavaScript
- Firebase Realtime Database
- GitHub Pages

## الاستخدام
1. افتح الرابط
2. المشرف ينشئ غرفة ويشارك الكود
3. المشاركون يدخلون بالكود ويضغطون الزر
